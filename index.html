Dono Runtime Backup

Dono Runtime Backup is a private-use utility that creates encrypted off-host backups of the owner's Dono Runtime staging environment and stores those backups in the owner's Google Drive.

Purpose

The application uses Google Drive access only to upload, verify, list, and manage encrypted backup files in a dedicated backup location controlled by the account owner.

Data handling

The application is not offered as a public service. It does not sell user data, use Google Drive data for advertising, or share Google Drive data with third parties. Backup contents are encrypted before off-host storage.
